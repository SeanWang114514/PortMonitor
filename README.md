# 端口占用监控器 (Port Monitor)

一个用于查看本机端口占用情况的桌面小工具，纯 Python + tkinter 编写，无需额外依赖即可运行。

![界面功能] 列表展示所有 TCP/UDP 连接：协议、本地地址、端口、外部地址、状态、PID、进程名、可执行文件路径。

## 功能特性

- 📊 **可视化仪表盘**：连接状态分布环形图、Top 进程 / Top 端口排行、连接数趋势曲线（纯 Canvas 自绘，零额外依赖）
- 📋 实时列出所有端口连接，按状态着色（监听=绿、已建立=蓝、TIME_WAIT=灰 等）
- 🔍 即时搜索过滤：支持**端口号** / 进程名 / PID / IP 地址
- 🎯 一键切换「仅监听端口」——查看"端口被谁占用"的最常用视图
- 🔄 自动刷新（3 秒间隔，可开关），也可按 F5 手动刷新
- ↔️ 点击表头排序（默认按端口号升序）
- 🗡️ 结束占用进程（`taskkill /F`，带二次确认）
- 📂 打开进程可执行文件所在目录（需 psutil 数据源）
- 📤 导出当前视图为 CSV（Excel 可直接打开）
- ⌨️ 快捷键：`Ctrl+F` 聚焦搜索、`F5` 刷新、`Esc` 清空搜索
- 🖱️ 右键行：复制地址 / 只显示该进程的连接 / 结束进程 / 打开目录
- 💬 双击行：复制 `地址:端口` 到剪贴板
- 🎛️ 双标签页界面：`端口列表` + `可视化仪表盘`，快捷键 `Ctrl+D` 直接切换

## 可视化仪表盘

顶部四张统计卡片 + 四张实时图表：

| 图表 | 说明 |
| --- | --- |
| 连接状态分布 | 环形图：LISTENING / ESTABLISHED / TIME_WAIT / CLOSE_WAIT / SYN_SENT / UDP 占比 |
| Top 进程连接数 | 横向条形图：连接数最多的前 8 个进程 |
| Top 端口连接数 | 横向条形图：被占用最多的前 8 个端口 |
| 连接数趋势 | 折线图：每次刷新采样一次，开启「自动刷新」后随时间累积（最多 120 个采样点） |

## 运行方式

### 方式一：双击启动（推荐）

直接双击 **`启动端口监控.bat`**（无控制台黑窗口）。

### 方式二：命令行

```bat
python port_monitor.py          :: 启动图形界面
python port_monitor.py --cli    :: 命令行模式，打印全部端口表
python port_monitor.py --cli 8080   :: 只看与 8080 相关的连接
```

## 依赖说明

- 基础运行只需 Python 3.8+（自带 tkinter），零第三方依赖；
- 可选安装 [psutil](https://pypi.org/project/psutil/) 以获得更快的扫描速度和**进程路径**信息：
  运行 `安装增强依赖.bat`，或执行 `pip install psutil`。

数据来源自动选择：已装 psutil 用 psutil，否则回退到 `netstat -ano` + `tasklist`。

## 常见问题

| 问题 | 说明 |
| --- | --- |
| 看不到某些端口 | 请取消勾选「仅监听端口」，或检查是否以管理员身份运行 |
| 结束进程失败 | 目标进程可能受保护，需要以**管理员身份**运行本软件 |
| 打开目录不可用 | 当前为 netstat 数据源（未装 psutil），不包含路径信息 |
| pythonw 双击无反应 | 查看同目录下的 `port_monitor.log` 错误日志 |

## 安全提示

「结束进程」会强制终止目标进程（不可恢复），操作前请确认该端口确实不再需要。结束**系统关键进程**可能导致程序崩溃或系统不稳定，请谨慎使用。
